# Nola

![Nola logo, retained from Magnolia](src/media/magnolia.png)

Nola is an experimental fork of [Magnolia](https://github.com/chwair/magnolia), a desktop media client. This fork is a place to try new features, explore changes, and gather feedback while keeping it practical to sync improvements from upstream.

Features and behavior may change as experiments develop. Nola keeps Magnolia's original logos and artwork, with credit to the upstream project and its contributors.

## Features

- Video playback powered by mpv
- Extensions for media sources and subtitles
- Subtitle imports for individual files or a full series
- Watch progress tracking and personal lists
- Media discovery and recommendations
- Live TV from free Pluto TV, Plex, Samsung TV Plus, and Roku Channel lineups, or any M3U playlist
- Desktop builds for Windows, macOS, and Linux

## Live TV

Select the live icon in the title bar to open **Live TV**. Add a free lineup from Pluto TV, Plex, Samsung TV Plus, or The Roku Channel by region, paste an M3U playlist URL, or import a local `.m3u`/`.m3u8` file. Browse by category, search, star favorites, and use **Page Up**/**Page Down** in the player to change channels.

The featured lineups use playlists generated by [app-m3u-generator](https://github.com/BuddyChewChew/app-m3u-generator), which is not affiliated with those services. Sources and channel lists are saved in `live_channels.json` in Nola's app data folder. Channel availability depends on each service and your region.

### Linux: Wayland and X11

The built-in player currently works on **Wayland** sessions only. On **X11**, opening a video or channel shows a blank window that looks transparent to the desktop. Until this is fixed, use a Wayland session (the default on most current GNOME and KDE desktops) or **Open in external player**. On Linux this needs mpv or VLC installed from your distribution, because the `.deb` does not include a standalone mpv.

Notes for fixing it:

- Video is drawn by `libsoia_utils` from the bundled [FengZeng/mpv](https://github.com/FengZeng/mpv) runtime, beneath the transparent webview. `main.rs` picks the embed mode from the window handle: Wayland uses mode 2, X11 (Xlib/Xcb) uses mode 1.
- Mode 2 renders through mpv's render API into a `wl_subsurface` below the webview, so the UI composites over the video.
- Mode 1 only passes mpv the window ID (`wid`). mpv and GTK then draw into the same X11 window, and GTK's transparent webview paints over the video. The Linux `libsoia_utils` has no X11 render-context path.
- A likely fix is a separate X11 path: render with mpv's OpenGL render API into a GTK `GLArea` placed under the webview in a `GtkOverlay`, so GTK composites both layers itself.
- This also affects upstream Magnolia, so check upstream and new FengZeng/mpv releases first.

## Building locally

### Prerequisites

- Node.js 22 and npm
- Rust stable
- Platform-specific Tauri build dependencies; see the [Nola build workflow](.github/workflows/nola-release.yml) for each platform's setup

### Setup

Use a disposable checkout for a Nola build. The branding step updates files in that checkout; keep those generated changes out of commits intended for upstream syncing.

```sh
git clone https://github.com/skonester/Nola.git
cd Nola

# Install JavaScript dependencies and runtime libraries
npm ci
npm run setup:libs

# Apply Nola branding
node scripts/prepare_nola.mjs

# Start the development app
npm run tauri:dev
```

To create a production build:

```sh
npm run tauri:build
```

See [Nola builds and releases](NOLA.md) for release publishing, versioning, branding, and upstream-sync instructions.
